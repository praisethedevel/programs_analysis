# Security Policy

## Reporting a Vulnerability

We take the security of our on-chain Solana programs seriously. If you discover a vulnerability or potential exploit in `CustomToken`, `CustomSysclock`, or `CustomRAM`, please submit a confidential report:

- **Email**: `xsolutionx@gmail.com`
- **Security Advisory**: https://github.com/praisethedevel/programs_analysis/security/advisories/new
- **PGP Fingerprint**: `FBFCEFA9 28CE443E BA132093 793A41D2`

Please do **not** disclose security vulnerabilities publicly or file public GitHub issues before responsible coordination and fix deployment.
